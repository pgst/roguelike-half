# ⚔️ ローグライクハーフ (Roguelike Half)

**〜 剣と魔法、そしてサイコロが紡ぐ、手のひらの上の迷宮踏破譚 〜**

本アプリケーションは、FT書房のライセンス規約に基づくテーブルトークRPG（TRPG）**「ローグライクハーフ」**の二次創作デジタルゲームブックSPA（Single Page Application）です。  
Webブラウザ上で、インストール不要・完全無料でソロプレイを楽しめます。スマートフォンおよびPCの両方に最適化されたレスポンシブな洋書風インターフェースで冒険をお楽しみいただけます。

---

## 🧭 主な特徴・魅力

### 1. 📜 クラシカルな洋書スタイルとd66迷宮探索
羊皮紙調の美しいビジュアルで、部屋を1つ進むごとに2つのサイコロ（d66）によってモンスターとの遭遇、罠、財宝、奇妙なイベントがリアルタイムに展開します。

### 2. 🎲 臨場感あふれるターン制ダイスバトル
- 通常攻撃、魔法呪文、奇跡、道具の使用、そして危険な状況からの逃走。
- 3D回転アニメーション付きの「運命のダイス」演出を搭載。設定から演出をOFFにして高速テキスト進行に切り替えることも可能です。
- 出目 `6` の会心クリティカルや、出目 `1` の痛恨ファンブルなど、ダイスゲームならではの一喜一憂を味わえます。

### 3. 🛡️ 冒険記録紙（キャラシート）と自由な育成
- 冒険中に得た経験点を技量点・生命点・副能力（魔術/幸運/腕力/敏捷）へ割り振る成長システム。
- 武器・防具・盾の装備切り替え、背負い袋のアイテム管理、そして頼もしい「従者」たちの雇用。
- 画面上部のミニステータスバーからいつでも「📜 ステータス詳細」を開いて確認できます。

### 4. ☁️ クラウド同期 ＆ 冒険の殿堂
- ゲスト冒険者（匿名）としてすぐにプレイ可能。
- Googleアカウントと連携することで、セーブデータをクラウドへ安全にバックアップし、PCとスマートフォンの間で続きをシームレスにプレイ可能。
- 迷宮の最深部に君臨する魔将を討ち破った歴代の英雄たちは「冒険の殿堂」に永久記録されます。

### 5. 🛠️ シナリオ工房（自作ダンジョン作成・共有）
- あなただけのオリジナルシナリオをブラウザ上で作成・編集できる「シナリオ工房」を内蔵。
- 部屋イベント、罠、出現エネミー、ボスの強さを自由に構築可能。
- 難易度を客観的に診断する「適正レベル自動計算機能」を搭載。
- 作成したシナリオは JSON ファイルとしてワンクリックでエクスポート・配布でき、他のプレイヤーが作ったシナリオを読み込んで遊ぶこともできます。

## 🎮 遊び方

1. **冒険者の作成**: 技量点・生命点・副能力値（魔術・幸運・腕力・敏捷）を決定し、あなたの分身となるキャラクターを作成します。
2. **シナリオ選択**: 挑むダンジョン（公式シナリオまたは自作シナリオ）を選択します。
3. **迷宮探索**: 部屋を進み、罠を解除し、魔物を討伐しながら最深部を目指します。
4. **決戦と帰還**: 最深部で待ち受ける魔将（ボス）を撃破して地上へ生還すると、経験点や名誉を獲得してさらなる高難度シナリオへ挑むことができます。

## 💻 開発・ローカル実行

本プロジェクトは Node.js 環境上で Vite を用いてビルド・開発されています。

### 必要な環境
- Node.js: 20.x 以上
- npm: 10.x 以上

### セットアップ手順

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173/)
npm run dev

# TypeScript型チェック & 本番ビルド
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```
